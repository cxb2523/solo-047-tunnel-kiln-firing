# 隧道窑烧成曲线与燃气单耗核算页

纯前端单页，无外部依赖。直接双击打开 `index.html` 即可（数据经 `data/kiln.js` 内联加载，file:// 下可用，无需起服务、无需联网）。

## 文件

- `index.html` / `styles.css` / `app.js` — 页面与全部核算逻辑（原生 JS + Canvas）
- `data/kiln.json` — 台账与逐刻记录原始数据（三座窑、120 台窑车、72h×15min）
- `data/kiln.js` — 由 `kiln.json` 生成的浏览器加载版，内容一致
- `tools/gen_data.js` — 数据生成器（Node 20：`node tools/gen_data.js`，确定性可复现）
- `tools/check.js` — 核算逻辑自检（`node tools/check.js`）

## 页面功能

- 上半：三带温度曲线（可切窑、可叠加实测/两口径燃气曲线）；下半：120 台窑车台账
- 点台账行：叠加该车 72h 经历温度与到带时刻；明细面板给出「推进时刻+各带时长」算出的到带时刻 vs 台账记录，差过 10 分钟标红不认
- 台账内直接改装车密度档，吨位、负荷、两口径燃气量与单耗即时重算
- 异常核算：升温速率越限、釉种温度越限、多窑同顶最大燃气（区分负荷真高/开度没退）、推进卡堵、熄火时段（单列）、风燃比失调（逐燃烧器）、釉种制品不符
- 两套运行口径对比：贴紧工艺卡 vs 单耗最小，各自合格车数、燃气总量、单耗，并指名两口径判定不一致的窑车
- 支持 URL 参数深链：`index.html?kiln=K2&car=C058&gas=1`

## 数据口径（页顶也有标注）

- 釉种与制品对不上时，以装车制品为准修正釉种
- 三号窑两支热电偶 1200℃ 平线按坏点剔除（共 3 段），带温取同带其余热电偶平均
- 燃气总量按各带燃烧器流量逐刻累加（0.25h/刻），不用全窑平均数
